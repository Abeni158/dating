# GLOBAL DATE

## Phase 0 - Audit and foundation

The project begins with a clean repository and a clear engineering plan. This repository is intentionally empty and will be built as a production-grade platform rather than a static demo.

### Objectives
- establish the stack and architecture
- define product phases and milestones
- document the system before significant implementation
- scaffold the initial technical foundation

### Current state
- repository is empty except for a `.gitkeep` placeholder
- no app stack or dependency setup exists yet
- no database or environment configuration exists yet

### Planned stack
- Next.js 14 + TypeScript
- PostgreSQL + Prisma ORM
- Redis for realtime and rate limiting
- WebSocket capability for chat and presence
- Tailwind-based design system
- Docker for local dev and deployment
- GitHub Actions for CI
- Playwright/Vitest for testing

### Immediate next step
Create project management artifacts and a minimal, viable foundation to support the first implementation phase.
